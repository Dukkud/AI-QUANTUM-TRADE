# AI-QUANTUM Protocol №1
1. Continue internal development and audit without stopping machine learning layers.
2. After an uploaded step: test → audit → report → STOP until explicit user confirmation.
3. Q1–Q9 learning/research continues in parallel where technically appropriate.
4. Learning cannot bypass Evidence, OOS, Calibration, Risk or Security.
5. Q9 is shadow-learning only unless separately governed promotion authorizes change.
6. Intermediate layers are local; GitHub publication is reserved for control points.
7. Never claim GitHub PASS from local tests.
8. Defect cycle: detect → establish root cause → immediately fix locally → regression → recheck affected contour → conclusion.
9. If GitHub Actions remaining allowance reaches 150–200 minutes, do not upload the next final control-point version until the user confirms replenishment/update.
