1. Continue internal development and audit of all layers without stopping the layers.
2. Internal audits are performed continuously and independently.
3. User-facing audit reports are issued at uploaded step/control-point completion, not for every internal layer.
4. After an uploaded step: test → audit → report → STOP before uploading the next step until explicit user confirmation.
5. Q1–Q9 machine learning/research continues in parallel where technically appropriate.
6. Parallel learning must not bypass Evidence, OOS, Calibration, Risk or Security gates.
7. Q9 is an active Self-Learning / Evolution agent and is shadow-training only unless a separately governed promotion process authorizes a change.
8. Quantum Core is a coordination layer, not an additional agent.
9. Intermediate layers may be prepared/tested locally; GitHub publication is reserved for control points according to the project policy.
10. Never claim GitHub PASS from local tests.
